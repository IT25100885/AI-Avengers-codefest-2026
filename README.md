# Ashen Era Agentic Search

SLIIT Codefest 2026 AI Competition

## Sub-track

1C — Searching the Way a Human Does

## Problem

Build an AI assistant capable of performing iterative,
multi-step document search over the Ashen Era Archive.

The system should:

1. Search the document corpus.
2. Analyse retrieved evidence.
3. Determine whether enough information has been found.
4. Generate a new search when information is missing.
5. Repeat until sufficient evidence is available.
6. Produce a grounded final answer.
