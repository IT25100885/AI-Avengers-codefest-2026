TECHNICAL DECISIONS RECORDED DURING THIS PERIOD
===============================================================================

1. Project Architecture
The system follows an iterative agentic search loop:
- search the document corpus,
- analyse retrieved evidence,
- determine whether evidence is sufficient,
- rewrite or generate the next search when information is missing,
- repeat until sufficient evidence is available,
- generate a grounded final answer.

2. Configuration Management
- API secrets are stored in local .env files.
- .env is excluded from Git.
- .env.example contains only variable names and safe placeholders.
- Team members use the same environment-variable names with their own credentials.

3. Evaluation
- Evaluation code can be developed independently from the full retrieval pipeline.
- Final validation requires integration with the completed search and answer components.
- Evaluation outputs are stored as structured JSON files for review.

4. Git and Collaboration
- Work is separated across branches to reduce conflicts.
- Commits should be meaningful and task-focused.
- Integration should be verified before merging into the main branch.
