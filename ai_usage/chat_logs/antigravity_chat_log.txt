================================================================================
User prompt:
  "Implement src/llm/client.py: a reusable Groq client using the OpenAI-compatible
   SDK, reading GROQ_API_KEY and LLM_MODEL from environment variables via
   python-dotenv. Include a call_llm(messages, model=None, temperature=0.2)
   function with retry/backoff using tenacity (max 5 attempts, exponential wait).
   Do not add pydantic. Show me the implementation plan first and wait for my
   confirmation before writing the file."

Follow-up requirement:
  "Good plan, proceed with this — but add one more function to src/llm/client.py:
   call_llm_json(messages, model=None, temperature=0.0, max_retries=2) -> dict.
   It should call call_llm, attempt json.loads() on the response (stripping
   markdown code fences if present), and if parsing fails, re-prompt the model
   with an instruction to return only valid JSON, up to max_retries times,
   raising ValueError if it still fails. This will be needed by the evidence
   checker. Export it from src/llm/__init__.py alongside call_llm and get_groq_client."

Implementation Details:
  - src/llm/client.py:
    * `get_groq_client(api_key=None, base_url=None) -> OpenAI`: Configures Groq
      endpoint (https://api.groq.com/openai/v1) with API key resolution.
    * `call_llm(messages, model=None, temperature=0.2, **kwargs) -> str`: Calls
      chat completions with @retry(stop=stop_after_attempt(5), wait=wait_exponential(min=2, max=30), reraise=True).
    * `call_llm_json(messages, model=None, temperature=0.0, max_retries=2, **kwargs) -> dict`:
      Regex-based markdown fence stripping (```json ... ```), JSON parsing, and
      conversational re-prompting on malformed outputs.
    * Zero pydantic imports (verified via AST inspection).
  - src/llm/__init__.py:
    * Exports `call_llm`, `call_llm_json`, `get_groq_client`.
  - requirements.txt & .env.example:
    * Added `openai>=1.0.0`, `python-dotenv>=1.0.0`, `tenacity>=8.0.0`.
    * Added `GROQ_API_KEY`, `LLM_MODEL`.

Testing & Verification:
  - 8/8 unit tests passed covering fence stripping, JSON parsing, retry logic,
    and missing API key handling.
